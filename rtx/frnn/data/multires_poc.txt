Multi-resolution SPH proof of concept (density stage), RTX 5000 Ada, N = 1,000,000, box 100, frozen particles.
Coarse particles fill the box except a central fine region (1/8 of the volume); fine particles have h smaller by `ratio`.
Both populations are spaced for ~80 neighbours. Density uses the scatter form: rho_i = sum_j m_j W(r_ij, h_j).
Grid = one uniform grid with cells sized for the coarse support radius. RT = Morton reorder + BVH rebuild + trace.
Every run cross-checked per particle (grid vs RT density, relative tolerance 1e-3; worst observed ~1e-6).
